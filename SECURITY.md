# Security reporting

Do not disclose credentials, private model files, or exploitable vulnerability details in public issues.
Use GitHub's **Report a vulnerability** option in the repository Security tab. If it is not available,
use a private contact method listed on GitHub before sharing sensitive details.

Include the affected revision, impact, prerequisites, and a minimal reproduction that uses synthetic
data. Do not attach decrypted model material, encryption secrets, or another person's data.

Security fixes target the default branch. Dependency checks and automated tests do not constitute a
security audit.
